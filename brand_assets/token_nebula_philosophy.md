# Token Nebula · 算法哲学

## 命名

**Token Nebula（token 星云）**

## 哲学

每一个 token 都是一颗微观的恒星，它独自发光时只是噪声，但当成千上万的 token 在引力场中相互吸引、彼此干涉、共同旋转时，便涌现出可被人类辨识的智能光晕。这正是大型语言模型推理过程的视觉隐喻：离散的概率分布，在注意力机制的引力下凝聚成有序的语义流形。

我们要呈现的，并非一个静止的字母 T，而是一个由数万个 token 粒子构成、在引力与扰动之间永不停歇地寻找平衡的发光生命体。中心是稳定的、被所有粒子共同朝拜的奇点；边缘是混沌的、不断被新粒子击穿又重组的星云外壳。整个系统在每一帧都在重新发明自己，但它的轮廓——那个隐约可辨的字母 T——始终岿然不动。这是秩序与混沌的双子谜题：精确的几何（T 的笔画）由不精确的过程（粒子的随机游走）书写而成。

算法的核心是一个分层的吸引-扰动场。第一层是 **形状吸引子**：每一个粒子在初始化时被赋予一个目标，这个目标位于字母 T 的笔画轮廓上的某个采样点；粒子受到指向目标的弹性力，但该弹性力被一个时间相关的衰减函数调制——离目标越近，吸引越柔和，从而避免粒子在 T 的轮廓上塌陷成生硬的笔画。第二层是 **柏林噪声扰动场**：低频的多倍频噪声场不断推搡粒子，使它们围绕目标做有机的呼吸式漂移，永远不静止。第三层是 **轨道层**：少量"先驱"粒子被赋予围绕中心的角动量，它们绘制出贯穿整幅作品的光环弧线，提供大尺度构图骨架。三层力的叠加产生既有清晰可识别字形、又充满活力星云感的最终图景。

色彩并非装饰，而是物理状态的可视化表达。每一个粒子的颜色由它的 **能量** 与 **位置** 共同决定：靠近字形核心的粒子能量充盈，呈温暖的桃橙色（#FF6B35 → #F7B7A3）——这是它们最稳定、最被吸引、最确信的颜色；位于星云外壳的低能量粒子则向冷色的薰衣草紫（#B5A8FF）漂移，象征它们正在远离结构、即将熄灭。中央的奇点是一个微小的高斯亮斑，永远是纯白炽热——它是整张图的眼睛，是 token 被精选出来的那一刻。

为了让这件作品在公众号头像的极小尺寸（64×64 像素）下仍然可识别，整个生成系统经过了精确的尺度校准：T 笔画的占比被锁定在画布的 36%–42%，确保即使粒子云模糊到只剩一团光，那个 T 字仍能被辨认；星云外壳的发光半径与画布对角线之比被微调至 0.55，使整体构图既有呼吸又不溢出；笔画交点处的粒子密度被刻意提升 3.2 倍，制造视觉锚点。这些参数没有一个是随便选的——每一个数值都是无数次反复观察、对比、推翻、重做的结晶。这是顶级生成艺术工程师的工艺自觉：每一个 magic number 都是一次美学决断的化石。

最终，每一颗 seed 都是一次平行宇宙的快照——同一个字母 T，但粒子的微观分布、星云的形状、奇点的位置、能量的潮汐都各不相同。用户每次按下"下一个"按钮，都不是在切换图片，而是在召唤这个生命体的一个全新化身。这种深度参数化的精雕细琢，正是大师级生成艺术家与普通程序员之间的分水岭——前者把每一个像素都视为有灵魂的决定。
