No. 01Anthropic 年化营收冲到 450 亿、半年反超 OpenAI 35%，IPO 主角悄悄换人

Source: 华尔街见闻 | Time: 2026-05-28 08:51

半年前（2025 年底）Anthropic 年化营收 90 亿美元，不到 OpenAI 的一半；今天 Anthropic 已达 ~450 亿美元，OpenAI 约 330 亿——Anthropic 高出至少 35%。今年前五个月，Anthropic 营收增长 ~5×，OpenAI 增长 >50%。盈利端反差更刺眼：Anthropic Q2 运营利润率约 5%（利润 ~5.59 亿），OpenAI Q1 运营亏损率 122%（亏损 ≥70 亿）。含义：(a) 这条线呼应昨日报告 #1（Sam Altman 撤回失业论）和 #3（Doctorow 警告"无白送基建"）——OpenAI 公开降温叙事的潜在动机，包括为更审慎的 IPO 估值预留时间；(b) 与本期 #4（Simon Willison 称"两家都已 PMF"）形成对话：PMF 已找到，但找到 PMF 的姿态完全不同，Anthropic 押注企业 API + 编码 Agent，OpenAI 押注 ChatGPT 消费端 + 计算资本开支；(c) IPO 路径预期翻转——以前默认 OpenAI 抢跑、Anthropic 跟跑，现在 Anthropic 估值叙事更顺，OpenAI 抢上反而成"财务上更审慎"的选项。

No. 04ESMFold2 与 Alex Rives：Bitter Lesson 烧到蛋白质，2.8 亿序列在抗体预测上反超 AlphaFold3

Source: Latent Space（Alex Rives, BioHub）| Time: 2026-05-27

ESM 团队延续"拒绝 MSA、押注无监督 + 规模"的路线，ESMFold2 训练数据扩展到 28 亿条蛋白序列，在 抗体预测（MSA 因高速突变不可用）这类最难的任务上反超 AlphaFold3。架构上拆分为 ESMC（语义世界模型）+ ESMFold2（专用预测头），并展示了"推理时 scaling"在癌症 / 免疫靶点上的有效性。含义：(a) 这是 LLM 之外，"Bitter Lesson"（Sutton 2019）在生命科学上第一个真正破壁的案例——AlphaFold2 当年用 MSA 这种"领域归纳偏置"赢得大众认知，但 ESMFold2 证明：当数据规模和算力够大时，领域 trick 会被压平；(b) 与昨日报告 #4（CMU 提出"模型睡眠"）形成有趣对照——一个在通过架构 trick 改 LLM，一个在用 LLM 思路杀进生物学；(c) 投资视角：蛋白质设计创业公司（包括 Profluent、Generate Bio、EvolutionaryScale 自身）将面临"是否被基础模型吃掉"的洗牌，护城河进一步从专用模型转向封闭数据 / 封闭实验回路。

No. 07一篇刺骨长文：为什么 AI Agent 至今无法真正修改软件系统

🔥 HN 头条 | phroneses.com

作者提出"加性 vs 变换性"鸿沟（Additive–Transformative Gap）：LLM 写新代码（加性）已经可以，但修改现有真实软件系统（变换性）依然不可靠——核心难点在于代理对隐式约束、契约、不变量的感知缺位。含义：(a) 这是今年最关键的"Agent 反方观点"之一，与昨日 #5（DeepSWE 防污染评测）目标一致——都是要捅破"benchmark 高分 ≠ 真实工程能力"的窗户纸；(b) 与本期 #4（CMU 模型睡眠）+ #6（Webflow Agentic）的乐观叙事形成必要对冲；(c) 对企业 CTO 最实用的判断：写新功能可以放手让 Agent 做，但维护性变更（重构、跨服务依赖修改、配置漂移修复）必须保留资深工程师 review——把这条规则写进团队工程规范，在 2026 下半年是节流而非保守。
